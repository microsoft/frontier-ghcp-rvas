# Team vocabulary

## Bootstrap

The one-time process that installs Launchpad and creates an environment.

## Environment kit

A collection of tools maintained by the developer productivity group. Some
older pages call this a workspace.

## Profile

The settings stored for an individual engineer after an environment kit has
been applied. Profiles are not templates.

## Service environment

The default kit for API teams. It includes the company runtime and local
database.

## Workspace

A checked-out repository after bootstrap is complete. The CLI reference also
uses this word for environment templates.
