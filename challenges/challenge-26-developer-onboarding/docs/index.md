# Launchpad developer setup

Launchpad helps engineers prepare a local workspace. This documentation was
assembled from several team wikis during the 2.0 release.

## Start here

Install the package, then list the available developer profiles.

<!-- check-example -->
```bash
npm install
npm run build
npm run launchpad -- profile list
```

If you need more detail, read the [setup guide](getting-started.md) or browse
the [CLI reference](reference/cli.md).
