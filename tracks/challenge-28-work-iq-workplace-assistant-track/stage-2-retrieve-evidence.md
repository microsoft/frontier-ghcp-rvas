# Stage 2: Retrieve Evidence and Map the Handoff

**Difficulty:** ⭐⭐ | **Time:** 60-75 min

## Tasks

1. Start with the smallest approved source, such as recent project meetings or
   messages. Retrieve only the time range agreed in Stage 1.
2. Build an evidence map of possible decisions, actions, risks, dependencies,
   and unknowns. Keep every finding tied to a source.
3. Add a second source only when the first source leaves a specific question
   unanswered. Write down why you need the extra source.
4. Separate observations from inferences. Record contradictions and missing
   owners or dates as gaps.
5. Review the evidence map with the Evidence Reviewer agent. Resolve
   unsupported claims before drafting the handoff.
6. At the midpoint, refine the Scoped Workplace Retrieval skill with any source
   or time-range checks that would have prevented irrelevant retrieval.

## Verification

- The evidence map stays within the approved project and time boundary
- Each proposed decision, action, risk, and dependency has a source reference
- Added sources address a named gap
- Contradictory information and missing fields remain visible
- The evidence review identifies no unsupported factual claims

## What Copilot Helps With vs. What Requires Your Judgment

Copilot can group related evidence and spot recurring topics. You decide which
sources belong in scope, whether the support is good enough, and when to stop.
