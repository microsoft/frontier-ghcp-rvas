# Stage 4: Apply the Approval Gate

**Difficulty:** ⭐⭐⭐ | **Time:** 45-60 min

## Tasks

1. Review the action register with the named delivery lead. Confirm factual
   accuracy, source accessibility, sensitive-content handling, and audience.
2. Record every item that the reviewer rejects, changes, or cannot confirm.
   Return rejected claims to the evidence map instead of editing them into
   fact.
3. Decide whether the approved handoff may be published to its intended
   location. Keep the final location within the scope agreed in Stage 1.
4. If the team wants to create tasks, send messages, or update a document,
   define each action separately with its target, audience, approval, and
   verification. Do not make bulk changes from the first handoff.
5. Run the Human Approval Gate skill before every proposed write action. Keep
   its review record beside the handoff.
6. Document the recurring trigger for this workflow, its owner, and when the
   project boundary must be reapproved.

## Verification

- A human reviewer has approved, rejected, or requested changes for the draft
- Rejected and unconfirmed items remain visible
- The publication decision matches the agreed audience and storage location
- Any future write action has its own explicit approval and verification plan
- The recurring workflow names an owner and boundary-review trigger

## What Copilot Helps With vs. What Requires Your Judgment

Copilot can compare the draft with the evidence map and prepare a review record.
You approve the final content, decide where it belongs, and authorize any
change to Microsoft 365 data.
