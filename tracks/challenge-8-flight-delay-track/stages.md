# Full-Stack Flight Delay Predictor: Phases

## Phases

This challenge is broken into four phases. Each phase builds on the previous one.

| Phase | Name | Duration | Focus |
|-------|------|----------|-------|
| 1 | [Data Exploration and Model Building](phase-1-data-exploration.md) | 3-4 hours | Jupyter Notebook, data science, machine learning |
| 2 | [Build the Prediction API](phase-2-prediction-api.md) | 2-3 hours | REST API, Flask or FastAPI, model serving |
| 3 | [Build the Frontend](phase-3-frontend.md) | 2-3 hours | Frontend, UI/UX, API integration |
| 4 | [Polish and Advanced Features](phase-4-polish.md) | 1-2 hours | Production readiness, stretch work |
