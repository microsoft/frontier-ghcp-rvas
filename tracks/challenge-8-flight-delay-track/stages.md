# Full-Stack Flight Delay Predictor: Stages

## Stages

This challenge is broken into four stages. Each stage builds on the previous one.

| Stage | Name | Duration | Focus |
|-------|------|----------|-------|
| 1 | [Data Exploration and Model Building](stage-1-data-exploration.md) | 3-4 hours | Jupyter Notebook, data science, machine learning |
| 2 | [Build the Prediction API](stage-2-prediction-api.md) | 2-3 hours | REST API, Flask or FastAPI, model serving |
| 3 | [Build the Frontend](stage-3-frontend.md) | 2-3 hours | Frontend, UI/UX, API integration |
| 4 | [Polish and Advanced Features](stage-4-polish.md) | 1-2 hours | Production readiness, stretch work |
