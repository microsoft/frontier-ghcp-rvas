# Full-Stack Flight Delay Predictor: Stages

## Stages

The core takes **five hours including setup**. Build one baseline model and
keep its two-feature contract consistent through the API and UI. Stage 4 is
optional and sits outside the core budget.

| Stage | Name | Duration | Focus |
|-------|------|----------|-------|
| Setup | [Environment and skills](../challenge-8-flight-delay-track.md#getting-started) | 30 min | Copilot customizations, manual Impeccable install |
| 1 | [Data Exploration and Model Building](stage-1-data-exploration.md) | 90 min | One two-feature baseline, evaluation, export |
| 2 | [Build the Prediction API](stage-2-prediction-api.md) | 60 min | Prediction and airport endpoints |
| 3 | [Build the Frontend](stage-3-frontend.md) | 120 min | Integrated form, one UI review and fix, tests |
| 4 | [Polish and Advanced Features](stage-4-polish.md) | Optional | Extra models, charts, deployment |

For a four-hour session, preflight setup and cap Stage 1 at 60 minutes. Keep
the model export, cross-layer checks, and prediction-flow review.
