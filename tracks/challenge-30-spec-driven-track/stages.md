# Spec-Driven Feature Delivery with GitHub Spec Kit: Stages

## Stages

| Stage | Name | Duration | What You Do |
|-------|------|----------|-------------|
| 1 | [Establish the Baseline](stage-1-baseline.md) | 30 min | Run the app, initialize Spec Kit, and agree project principles |
| 2 | [Specify the Approval Feature](stage-2-specification.md) | 60 min | Resolve the incomplete request and review acceptance scenarios |
| 3 | [Plan Against the Existing App](stage-3-plan.md) | 45 min | Derive tasks and resolve consistency findings before coding |
| 4 | [Implement and Verify](stage-4-implementation.md) | 105 min | Add approvals to the API and UI with regression evidence |
| 5 | [Change the Rules](stage-5-change.md) | 60 min | Revise the living specification and implement a second approval |

The core totals five hours. Work solo or in pairs. If you need to cut scope,
skip optional customizations and keep the UI simple. **The requirement change
is part of completion**, not a stretch goal.
