Build your first session.

Work through these steps in order. You can come back and adjust them as the challenge takes shape.

  1. Define the result with the Outcome Canvas. Be specific about what the team should produce.
  2. Split the work into 3-5 stages. Give each stage one useful result that a team can finish in 45-90 minutes.
  3. Write the challenge with the templates. Fill in the track, stage, and metadata files.
  4. Prepare the environment. Set up a Codespace, container, or local development environment with the repository, dependencies, and required credentials.
  5. Run the session with the Facilitator Runbook. Keep the stages on time, help with blockers, and review the final demos.
  6. Review the result with the Outcome Scorecard. Check whether the work runs, solves the stated problem, and can be explained clearly.
